模拟 Agent 数据 · 自动构造响应和通知

维护业务值即可：Studio 读取 App 请求中的 sessionId、cwd、configId、value 等，自动查询或更新同一份模拟数据，构造对应的 response 和 notification。

Agent 可选值与默认值

models 定义可选模型，defaultModel 指定新会话默认模型；provider/model 配置项自动生成。configOptions 中维护 mode 等 select 配置的选项与 defaultValue。projects、temporaryWorkingDir 和 capabilities 供相关接口查询。

更新可选值会同步到已有会话，合法的当前值保留，已移除的值回退到默认值；默认值主要用于新会话。

会话与用户当前值

values 保存该会话的 provider、model、mode 等当前值。cwd 对应项目 path 或临时工作目录；sessionId 为空时生成新 ID，同 ID 保存修改原会话，新 ID 保存新增会话。

App 调用 set_config_option 后会更新这些值并收到配置通知；点击读取可查看。此处保存后，在 App 重新加载或查询会话即可读取新值。已有消息历史保留。

默认 Mock 与样例来源 / 编辑说明

默认 Mock 来自 examples/desktop-catalog.json 的调试文档片段、agent.py 的本地状态与默认值；prompt 默认使用 examples/desktop-prompt.json，无文档样例时使用 examples/reply.json。它们是模拟参考数据，不是实时 Desktop 数据。

编辑请求方法：选择方法 → 修改 result 或完整 frames → 应用 → 在 App 重新触发请求。$result / $notifications 表示动态生成；需要自定义具体字段时，将占位符替换为完整对象或通知帧。session/new 的 sessionId 使用 $sessionId；历史分页使用 $pageId，updateCount 与通知数一致，sequence 从 0 连续递增。

编辑通知样例：选择样例 → 载入通知单独编辑 → 修改 name、message.method、params 等 → 保存通知样例。同名覆盖，修改 name 另存。用于请求流程时，选择请求方法与通知样例 → 插入到当前方法 → 检查 frames → 应用。插入的是副本，之后修改样例不会自动修改已配置的方法。
